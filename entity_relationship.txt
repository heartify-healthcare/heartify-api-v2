**User** (user_id : UUID, PK)
Attributes:

* username : varchar
* email : varchar
* phonenumber : varchar
* password : varchar
* is_verified : boolean
* role : varchar
* created_at : datetime
* dob : date
* sex : int
* cp : int
* trestbps : int
* exang : int
  Relationships:
* 1–to–many with OTP (user_id as FK)
* 1–to–many with ECGSession (user_id as FK)

---

**OTP** (otp_id : UUID, PK)
Attributes:

* user_id : UUID (FK → User.user_id)
* otp_code : varchar
* expired_time : int
* otp_used : boolean
* created_at : datetime
  Relationships:
* Many–to–1 with User

---

**ECGRecording** (ecg_id : UUID, PK)
Attributes:

* raw_data : json
* denoised_data : json
* sampling_rate : int
* recorded_at : datetime
  Relationships:
* 1–to–many with ECGSession (ecg_id as FK)

---

**Prediction** (prediction_id : UUID, PK)
Attributes:

* model_version : int
* diagnosis : varchar
* probability : float
* features : json
* created_at : datetime
  Relationships:
* 1–to–many with ECGSession (prediction_id as FK)

---

**Explanation** (explanation_id : UUID, PK)
Attributes:

* llm_model_version : int
* prompt : json
* explanation : json
* created_at : datetime
  Relationships:
* 1–to–many with ECGSession (explanation_id as FK)

---

**ECGSession** (session_id : UUID, PK)
Attributes:

* user_id : UUID (FK → User.user_id)
* device_id : UUID
* created_at : datetime
* ecg_id : UUID (FK → ECGRecording.ecg_id)
* prediction_id : UUID (FK → Prediction.prediction_id)
* explanation_id : UUID (FK → Explanation.explanation_id)
  Relationships:
* Many–to–1 with User
* Many–to–1 with ECGRecording
* Many–to–1 with Prediction
* Many–to–1 with Explanation

---

**Database separation:**

* User Database: User, OTP
* AI Database: ECGRecording, Prediction, Explanation, ECGSession
